## 🧠 Mental Health Score Prediction

A Machine Learning project that predicts a student's mental health score based on input features using a trained ML pipeline.

### Tech Stack
- Python
- Pandas & NumPy
- Scikit-learn
- FastAPI
- REST API
- Render (Deployment)

### Key Features
- Data preprocessing and feature engineering
- Machine Learning model training using Random Forest Regression
- Integrated preprocessing and prediction pipeline
- FastAPI endpoint for generating predictions
- Cloud deployment for API access

### Live Demo
- **API:** https://mental-health-score-zqix.onrender.com/
- **GitHub Repository:** https://github.com/sahil-0905/Mental_Health_Score

### Learning Outcomes
- End-to-end Machine Learning workflow
- Model serialization and loading
- REST API development using FastAPI
- Deploying an ML model to the cloud

> **Note:** This project provides ML-based predictions and is not a substitute for professional mental health assessment or diagnosis.
